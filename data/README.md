# 月度研究数据

`GW05_original_monthly.csv`为原项目保存的Goyal–Welch2005年末数据快照，分号分隔，逗号为小数分隔符。该表包含公开研究中的市场与宏观时间序列，无个人数据。

原始研究与数据说明见[Goyal–Welch论文](https://www.ivo-welch.info/research/journalcopy/2008-rfs.pdf)及[Amit Goyal个人主页](https://sites.google.com/view/agoyal145)。后续更新版本可能修订历史数据，使用不同快照不保证得到相同结果。

SHA256：`807b97645968c543548f62be295a5f99573c05948f491c1d6a071ca2a7de1159`。
