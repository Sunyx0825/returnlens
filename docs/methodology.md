# 研究方法

## 数据与变量

目标为CRSP价值加权市场总收益减去无风险利率，使用简单月收益。15个预测变量分别进入含截距的单变量回归。

| 变量 | 定义 |
|---|---|
| dp | log(D12)－log(Index) |
| dy | log(D12)－log(上月Index) |
| ep | log(E12)－log(Index) |
| de | log(D12)－log(E12) |
| e10p | log(过去120个月E12均值)－log(Index)；本项目的名义平滑盈利代理变量 |
| tms | 长期国债收益率lty－短期国债利率tbl |
| dfy | BAA公司债收益率－AAA公司债收益率 |
| svar、lty、ltr、infl、tbl、b/m、csp、ntis | 使用数据快照对应列 |

特征从1927年11月开始构造，研究区间从1927年12月开始。`e10p`需要120个月预热，因此早期有效回归样本较少；缺失值不会用后续观测填补。该代理变量的构造及初始样本安排属于本项目设定，不将结果视作原论文每张表的逐项复制。

## 时间窗口

第一个预测原点为1947年12月，目标月份为1948年1月。首个估计窗口包含241个月度行，普通变量形成240个滞后配对。`csp`可用期较短，窗口从1937年5月开始，测试期为1957年6月至2002年12月。其余变量测试至2005年12月。

普通变量的估计配对为`r[t] ~ x[t-1]`，预测为`r[t+1] ~ x[t]`。通胀额外延迟一个月，配对和预测分别为`r[t] ~ infl[t-2]`、`r[t+1] ~ infl[t-1]`。

每次OLS仅使用截止预测原点的有限数值配对。求解采用NumPy伪逆，阈值`rcond=1e-15`。数据日期必须连续、唯一、递增。

## 两项预测约束

初始窗口估计的斜率正负号固定用于后续预测。若某期斜率与该方向冲突，将该期斜率置零，保留当期OLS截距；之后将预测值限制为不低于零。这是显式的预测修正规则，未在斜率归零后重新估计截距。

符号约束与非负预测截断均属于已有文献中的约束思路。本项目的实证贡献是将这些约束落实为信息时点一致、可逐期复核的研究流程，并报告全部变量的比较。

## 指标

`OOS R² = 1 - SSE(model) / SSE(expanding historical mean)`。

CSV以百分数记录R²，`improvement_pp`为两者的百分点差。正R²等价于相同测试集上的模型MSE低于历史均值MSE。没有将预测值映射为投资头寸，也未据此计算策略收益。

## 结果的解释

12个模型误差下降，`ltr`与`tms`略降，`svar`不变。8个模型胜过历史均值，但领先幅度较小。这些结果描述当前数据版本、样本和约束规则下的预测比较，未进行事后挑选变量或测试集参数搜索。
